# 🏠 СчитайДом

**СчитайДом** — бесплатное Windows-приложение для домашнего учёта коммунальных услуг, показаний счётчиков и расходов.

## Возможности

- Учёт коммунальных услуг
- Учёт показаний счётчиков
- Настройка тарифов
- Расчёт расходов
- История по месяцам и годам
- Диаграммы расходов
- Хранение данных локально на компьютере
- Резервное копирование данных

## 🔒 Конфиденциальность

СчитайДом не требует регистрации.  
Данные пользователя хранятся локально на его компьютере.

## 💻 Системные требования

- Windows 10 / Windows 11
- 64-bit (x64)
