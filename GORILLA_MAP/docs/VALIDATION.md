# Проверки сборки 0.1.0

Выполнено в облачной Linux-среде:

- Сверка сигнатур MapWidget, CanvasWidget, UIScriptedMenu, PlayerIdentity, ScriptRPC, JsonFileLoader, UAInput и методов виджетов с официальным DayZ-Script-Diff, commit `e8204c69fcfd056ea29a9728990fd9f7941ce8a6`.
- Статическая проверка структуры исходников, объявлений клавиши, имён виджетов и путей текстур/модулей скриптов.
- Проверка JSON демонстрационного конфига и пределов координат Черноруссии.
- Проверка 37 оригинальных DXT5 PAA независимым декодером armake; декодирование не является проверкой рендеринга DayZ.
- 11 тестов упаковщика: бинарный round-trip, формат заголовка, повреждение, обрезка, небезопасные пути, дубли имён, воспроизводимость, символьные ссылки и исключение закрытых ключей.
- Упаковка PBO, проверка префикса GorillaMap, контрольной суммы и полного побайтного соответствия исходникам.
- Чтение собранного PBO независимым инспектором armake.

Не выполнялось: компиляция Enforce в DayZDiag/DayZ, рендеринг native layout в игре, установка на dedicated, мультиплеер двух игроков, рестарт с реальными сохранениями DayZ, испытание подписи. Клиента, dedicated и DSUtils в этой среде нет. Версия API в PDF не принимается за доказательство версии игры.

PBO **не подписан**, поддельные `.bisign`/`.bikey` не создавались. Архив предназначен для дальнейшего игрового испытания по TESTING.md.
