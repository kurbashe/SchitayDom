# Проверки сборки 0.1.3

На предоставленном пользователем скриншоте DayZ 1.30.164200 подтвердил ошибку компиляции Mission в версии 0.1.1: `GMapMenu.c(243): Operator ++ is not supported on temporary values (TODO)`. Причина — `counts[marker.Kind]++`. В 0.1.2 это заменено явным присваиванием `counts[marker.Kind] = counts[marker.Kind] + 1`. Повторная компиляция исправленной версии в игре пока не подтверждена.

По следующему скриншоту пользователя подтверждено: виден полноэкранный фон карты без панели, остаётся штатный HUD; пользователь сообщает о блокировке карты и отсутствии меток. Скриншот не устанавливает, какое меню открыла клавиша M.

В 0.1.3 добавлены явные native `priority`/видимость/активность виджетов, подключение обработчика MapWidget и кнопок, парное скрытие/восстановление HUD, Escape через UAUIBack до ранних выходов, закрытие при неполном layout, отдельное действие F6 и диагностические сообщения. Эти исправления ещё не проверены в DayZ; причины отсутствия панели и конфликта M нельзя считать подтверждёнными без игрового журнала/повторного запуска.

Выполнено в облачной Linux-среде:

- Сверка сигнатур MapWidget, CanvasWidget, UIScriptedMenu, PlayerIdentity, ScriptRPC, JsonFileLoader, UAInput и методов виджетов с официальным DayZ-Script-Diff, commit `e8204c69fcfd056ea29a9728990fd9f7941ce8a6`.
- Три регрессионных теста проверки неподдерживаемых индексных ++/--, корректного присваивания и пропуска комментариев/строк.
- Пять геометрических проверок native layout: порядок слоёв, пассивные overlays, стартовая видимость модальных окон, активность кнопок и расположение панелей от 720p до ultrawide.
- Статическая проверка структуры исходников, объявлений клавиши, имён виджетов и путей текстур/модулей скриптов.
- Проверка JSON демонстрационного конфига и пределов координат Черноруссии.
- Проверка 37 оригинальных DXT5 PAA независимым декодером armake; декодирование не является проверкой рендеринга DayZ.
- 15 тестов упаковщика: бинарный round-trip, формат заголовка, повреждение, обрезка, небезопасные пути, дубли имён, воспроизводимость, символьные ссылки, исключение закрытых ключей и границы двух пакетов.
- Проверка отсутствия серверных классов в общем/клиентском PBO и GUI в серверном PBO; явная зависимость GorillaMapServer от GorillaMap.
- Упаковка обоих PBO, проверка префиксов GorillaMap/GorillaMapServer, контрольных сумм и полного побайтного соответствия исходникам.
- Чтение обоих собранных PBO независимым инспектором armake.

В этой облачной среде не выполнялось: компиляция Enforce в DayZDiag/DayZ, рендеринг native layout в игре, установка на dedicated, мультиплеер двух игроков, рестарт с реальными сохранениями DayZ, испытание подписи. Клиента, dedicated и DSUtils в этой среде нет. Версия API в PDF не принимается за доказательство версии игры.

PBO **не подписан**, поддельные `.bisign`/`.bikey` не создавались. Архив предназначен для дальнейшего игрового испытания по TESTING.md.
