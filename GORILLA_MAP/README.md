# GORILLA MAP — Черноруссия

Исходный мод DayZ с современным интерфейсом карты по предоставленному референсу. Самостоятельный: CF, Expansion и VPP не требуются.

**Статус 0.1.0: исходники и неподписанный PBO для испытаний.** Структура PBO, ресурсы и статические ссылки проверены. Компиляция Enforce, запуск DayZ и испытание двух игроков в этой среде не выполнялись. Архив нельзя считать проверенным публичным релизом.

## Что реализовано

- Полноэкранный штатный `MapWidget` Черноруссии: масштабирование, перемещение, координаты мира.
- Тёмная скруглённая боковая панель, цветные категории, оригинальные иконки, компас и панель подсказок.
- Серверные метки, серверные зоны, обозначения запрета строительства, личные и групповые метки.
- Создание и редактирование названия, координат, значка и цвета. Скрытие отдельных меток и сворачивание категорий.
- Серверное хранение личных меток и групп. Персонаж после смерти сохраняет свои метки через идентичность игрока.
- Самостоятельные группы: создание, выбор игрока по имени, приглашение, принятие/отклонение и выход. Общие метки доступны только членам группы.
- Метку группы изменяет автор или лидер. Лидер, покидающий группу, распускает её и удаляет общие метки; интерфейс запрашивает подтверждение.
- Отображение собственной позиции, настройки подписей/границ зон, линейка и копирование координат.
- Проверки серверных прав, границ карты и допустимых значений; лимиты меток и частоты запросов. Повреждённые серверные JSON не заменяются пустыми настройками.

Спутниковая картинка из референса не включена. Рельеф, дороги и подписи предоставляет текущая карта игры; оформление интерфейса создано отдельно. Круги радиации и запрета строительства **только обозначают зоны** — они не наносят урон и не запрещают игровые действия. Групповые метки включены; автоматическое слежение за координатами других участников не реализовано.

## Установка для испытания

1. Распакуйте `dist/GORILLA_MAP.zip`.
2. Скопируйте `@GorillaMap` в каталог сервера и в каталог модов клиента.
3. Добавьте `@GorillaMap` в `-mod` **на сервере и клиенте**, например `"-mod=@GorillaMap"`. Если там уже есть моды, добавьте имя через `;`. Использование только `-serverMod` не подходит: интерфейс и скрипты необходимы клиенту.
4. Укажите обычный серверный профиль, например `-profiles=ServerProfile`. При первом запуске создаются `GorillaMap/Config.json` и `GorillaMap/State.json` внутри этого профиля.
5. По желанию **перед первым запуском**, либо при остановленном сервере после резервной копии существующего конфига, установите образец `ServerProfile/GorillaMap/Config.json` из архива. Он содержит три демонстрационные метки. Автоматически созданный конфиг содержит пустой список меток.
6. Запускайте миссию `dayzOffline.chernarusplus`. Подключитесь клиентом и нажмите **M**.

PBO в архиве не подписан. Для сервера с `verifySignatures=2` подпишите его своим ключом DSUtils и установите публичный `.bikey`; инструкция находится в [docs/BUILD.md](docs/BUILD.md). Настройки проверки подписей изменять не требуется.

## Управление

| Действие | Управление |
|---|---|
| Открыть карту | **M**, переназначается в управлении → GORILLA MAP |
| Закрыть карту/окно | **Esc** или кнопка закрытия |
| Переместить/масштабировать карту | Перетаскивание ЛКМ / колесо |
| Создать метку | Двойной щелчок по карте или «Создать метку» |
| Выбрать и показать метку | Нажатие строки в списке |
| Редактировать | Кнопка `⋮` или ПКМ по редактируемой метке |
| Удалить | Корзина → «Удалить метку» → подтверждение |
| Скрыть/показать метку | Значок глаза |
| Вернуться к своей позиции | Кнопка прицела возле координат |
| Линейка | **Ctrl+L**, затем две точки на карте; повторное нажатие выключает |
| Скопировать координаты курсора | **Ctrl+C** |
| Группа | Нижняя кнопка «Группа» → создать/выбрать игрока/пригласить |

Для новой групповой метки выберите «Видимость: группа» в редакторе. Видимость существующей метки не переносится между личным и групповым хранилищами; создайте новую метку нужного типа. Приглашённый игрок открывает карту → «Группа» → «Принять». Приглашения действуют 10 минут и не сохраняются после рестарта. Снимок данных обновляется раз в 3 секунды, пока карта открыта.

Отключите совпадающее назначение M у другого мода карты, если возникает конфликт. Ванильная проверка открытия карты вызывается после открытия GORILLA MAP, чтобы два окна не открывались одновременно.

## Настройки сервера

`$profile:GorillaMap/Config.json` загружается при запуске. После редактирования перезапустите сервер. Версия схемы — `1`.

| Поле | По умолчанию | Значение |
|---|---:|---|
| `WorldName` | `chernarusplus` | Должно совпадать с миром сервера |
| `WorldSize` | `15360` | Граница координат X и Z |
| `ShowPlayerPosition` | `true` | Разрешает показ своей позиции и центрирование |
| `MaxPersonalMarkers` | `80` | До 200 |
| `MaxGroupMarkers` | `100` | До 200 |
| `MaxGroupMembers` | `8` | От 2 до 32 |
| `MaxGroups` | `1000` | Максимум сохранённых групп |
| `MaxAccounts` | `10000` | Максимум сохранённых профилей игроков |
| `Markers` | `[]` | До 200 серверных меток/зон |

Пример серверной зоны:

```json
{
  "Id": "balota_example",
  "Name": "Пример зоны: Балота",
  "Position": [4880, 0, 2500],
  "Color": -16128,
  "Icon": "radiation",
  "Kind": 1,
  "Radius": 350,
  "OwnerUid": ""
}
```

`Position` — `[X, Y, Z]` в метрах; карта использует X и Z. `Radius` — радиус круга в метрах. `Color` — знаковое 32-битное ARGB. `Kind`: `0` серверная метка, `1` серверная зона, `2` запрет строительства. Типы `3` и `4` создаются серверной логикой для личных и групповых меток. `Id` должен быть уникальным.

Значки: `pin`, `home`, `skull`, `star`, `water`, `medical`, `camp`, `radiation`, `prohibited`. Название — до 48 символов UTF-8. Серверные метки нельзя менять через клиентский RPC.

## Сохранения и восстановление

Сервер хранит `State.json`, предыдущую копию `State.json.bak` и временный файл `State.json.pending`. Файл состояния объединяет личные метки и группы; идентификаторы берутся из `PlayerIdentity.GetId()` на сервере. Данные чужих личных меток и других групп клиенту не передаются.

Изменение записывается в `.pending`, перечитывается для проверки, затем сохраняется предыдущая копия и обновляется основной файл. Это не атомарная транзакция файловой системы. При ошибке запись отключается, изменения в памяти откатываются; существующие файлы сохраняются для восстановления. Если основной файл повреждён/утрачен, нет автоматического сброса прогресса.

Для восстановления остановите сервер, сохраните **все** три файла вне рабочего каталога, проверьте содержимое резервной/временной копии, восстановите выбранное корректное состояние как `State.json` и перезапустите сервер. При намеренном полном сбросе также сначала сделайте архив всех файлов. Конфиг и состояние резервируются отдельно от мира `storage_1`.

Локальные настройки интерфейса находятся **у клиента** в `$profile:GorillaMapClient.json`. Они содержат масштаб/центр карты, скрытые метки и настройки отображения, но не серверные права. Эти настройки общие для данного клиентского профиля.
