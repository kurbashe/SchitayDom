# GORILLA MAP 0.1.1 — Черноруссия

Мод карты DayZ по предоставленному макету. Без CF/Expansion. Поставка разделена на **два PBO**: общий/клиентский и серверный.

Версия для испытаний: проверены исходники и упаковка; компиляция Enforce и работа в DayZ здесь не проверены. PBO не подписаны.

## Что создаётся автоматически

При запуске серверный пакет создаёт **только JSON настроек и состояния** в серверном профиле. Он не создаёт PBO и не устанавливает интерфейс игрокам.

Игрок устанавливает общий/клиентский `@GorillaMap`; администратор устанавливает на сервер **оба** пакета. Общий пакет нужен серверу для описания сетевого протокола и типов данных. Серверные решения и сохранение вынесены в отдельный `@GorillaMapServer`.

## Какие файлы куда класть

| Путь | Назначение | Где устанавливать |
|---|---|---|
| `@GorillaMap/addons/gorillamap.pbo` | Общий протокол, клиентский RPC, интерфейс, клавиша, графика | Клиент и сервер через `-mod` |
| `@GorillaMap/mod.cpp` | Метаданные общего/клиентского пакета | Оставить в `@GorillaMap` |
| `@GorillaMap/keys/README.txt` | Пояснение о подписи; не ключ | Инструкция |
| `@GorillaMapServer/addons/gorillamap_server.pbo` | Права, группы, серверные метки, JSON, обработка запросов | Только сервер через `-serverMod` |
| `@GorillaMapServer/mod.cpp` | Метаданные серверного пакета | Оставить в `@GorillaMapServer` |
| `ServerProfile/GorillaMap/Config.json` | Необязательный конфиг с демонстрационными метками | `<серверный -profiles>/GorillaMap/Config.json` |
| `Source/GorillaMap/` | Исходники общего/клиентского пакета | Только для разработки |
| `Source/GorillaMapServer/` | Исходники серверного пакета | Только для разработки |
| `tools/` | Сборщик и проверки | Только для разработки |
| `docs/` | Архитектура, сборка, игровые проверки | Документация |
| Корневые `mod.cpp`, `mod_server.cpp` | Шаблоны метаданных для сборщика | При установке использовать готовые папки `@...` |
| `build-manifest.json` | Контрольные суммы обоих PBO | Для проверки сборки |

Серверные классы `GMapService`, `GMapConfig`, `GMapStore`, `GMapGroup` и `MissionServer` отсутствуют в клиентском PBO. Серверный PBO не содержит GUI и текстур.

## Установка на сервер

Остановите сервер. При обновлении с 0.1.0 **замените прежний монолитный `gorillamap.pbo` новым**. Не оставляйте старый PBO рядом под другим именем: классы будут дублироваться. Сделайте резервную копию профиля `GorillaMap`; существующий `State.json` удалять не нужно, схема сохранена.

Скопируйте обе папки из архива рядом с исполняемым файлом сервера:

```text
DayZServer/
├─ DayZServer_x64.exe
├─ serverDZ.cfg
├─ @GorillaMap/
│  ├─ mod.cpp
│  └─ addons/gorillamap.pbo
├─ @GorillaMapServer/
│  ├─ mod.cpp
│  └─ addons/gorillamap_server.pbo
└─ profiles/GorillaMap/
   ├─ Config.json
   └─ State.json
```

Добавьте к параметрам запуска:

```bat
"-mod=@GorillaMap" "-serverMod=@GorillaMapServer" "-profiles=profiles"
```

Если списки модов уже есть, допишите имена через `;`, сохраняя остальные моды и существующий путь `-profiles`:

```bat
"-mod=@CF;@OtherClientMod;@GorillaMap" "-serverMod=@OtherServerMod;@GorillaMapServer"
```

Миссия — `dayzOffline.chernarusplus`. Серверный пакет зависит от общего аддона `GorillaMap`; устанавливать только `@GorillaMapServer` недостаточно.

## Установка игроку

Скопируйте **только `@GorillaMap`** в каталог модов клиента. В официальном лаунчере: «Моды» → «Локальный мод» → выбрать `@GorillaMap` → включить. При ручном запуске:

```bat
"-mod=@GorillaMap"
```

`@GorillaMapServer` игрокам устанавливать не нужно. У сервера и игроков должна быть одинаковая версия общего PBO. Установка серверного пакета не скачивает клиентский пакет другим компьютерам; для текущего локального архива это ручная установка.

## Подпись

Для сервера с `verifySignatures=2` подпишите общий PBO своим ключом DSUtils: `.bisign` распространяется рядом с клиентским PBO, публичный `.bikey` устанавливается в корневую серверную папку `keys/`. Закрытый `.biprivatekey` не распространяется. Серверный пакет загружается через `-serverMod` и не требуется клиентам. В архиве нет фиктивных подписей. Инструкция: [docs/BUILD.md](docs/BUILD.md).

## Возможности и управление

Тёмная панель, пять категорий, личные/серверные/групповые метки, редактор, группы с приглашением по имени, сохранение на сервере, проверка прав и лимитов, линейка, координаты и настройки видимости.

Фон карты штатный. Спутниковая текстура из макета не включена. Зоны радиации и запрета строительства — **визуальные обозначения**, без урона и блокировки действий. Автоматического слежения за позицией участников группы нет.

| Действие | Управление |
|---|---|
| Открыть карту | **M**, переназначается в управлении → GORILLA MAP |
| Закрыть окно/карту | **Esc** или кнопка закрытия |
| Передвижение/масштаб | Перетаскивание ЛКМ / колесо |
| Создать метку | Двойной щелчок либо «Создать метку» |
| Редактировать | `⋮` в строке или ПКМ по редактируемой метке |
| Удалить | Корзина → удаление в редакторе → подтверждение |
| Скрыть/показать | Значок глаза |
| Линейка | **Ctrl+L**, затем две точки |
| Скопировать координаты | **Ctrl+C** |
| Группа | Нижняя кнопка «Группа» |

Приглашённый игрок открывает «Группа» → «Принять». Приглашение действует 10 минут и не переживает рестарт. Общая метка создаётся с видимостью «Группа»; существующая метка не переносится между личным и общим хранилищем. Метку группы изменяет автор или лидер. Выход лидера после подтверждения распускает группу и удаляет её общие метки. Снимок обновляется раз в 3 секунды, пока карта открыта.

## Серверный конфиг

`Config.json` находится в `<серверный -profiles>/GorillaMap/`. Автоматически созданный конфиг содержит пустой список меток. Необязательный образец содержит три демонстрационные метки; устанавливайте его при остановленном сервере после копии своего конфига. Для изменения настроек нужен рестарт.

| Поле | По умолчанию | Значение |
|---|---:|---|
| `Version` | `1` | Версия схемы |
| `WorldName` | `chernarusplus` | Мир сервера |
| `WorldSize` | `15360` | Граница X и Z |
| `ShowPlayerPosition` | `true` | Показ своей позиции |
| `MaxPersonalMarkers` | `80` | До 200 |
| `MaxGroupMarkers` | `100` | До 200 |
| `MaxGroupMembers` | `8` | От 2 до 32 |
| `MaxGroups` | `1000` | Лимит групп |
| `MaxAccounts` | `10000` | Лимит профилей |
| `Markers` | `[]` | До 200 серверных меток/зон |

Метка: `Id` — уникальная строка; `Name` — до 48 символов UTF-8; `Position` — `[X,Y,Z]` в метрах; `Color` — знаковое 32-битное ARGB; `Radius` — радиус круга. `Kind`: `0` серверная метка, `1` зона, `2` запрет строительства; типы `3`/`4` создаёт сервер для личных/групповых меток.

Значки: `pin`, `home`, `skull`, `star`, `water`, `medical`, `camp`, `radiation`, `prohibited`. Клиент не может изменять серверные метки.

## Сохранение

`State.json` содержит личные метки и группы; сервер использует `PlayerIdentity.GetId()` из игрового контекста. Клиент получает только собственные личные и доступные групповые метки. Права не берутся из клиентского файла.

Запись использует `State.json.pending`, перечитывание для проверки и предыдущую копию `State.json.bak`. Это не атомарная транзакция. Ошибка сохранения отключает сервис и откатывает память; повреждённый JSON не заменяется пустым состоянием.

Для восстановления остановите сервер, сохраните все три файла вне рабочей папки, проверьте backup/pending, восстановите корректную копию как `State.json` и перезапустите сервер. Этот профиль резервируется отдельно от `storage_1`.

Клиентский `$profile:GorillaMapClient.json` содержит масштаб/центр, скрытые метки и настройки отображения.

## Разработка

```bat
python tools/test_packaging.py
python tools/verify.py
python tools/build.py
python tools/verify.py --pbo dist/@GorillaMap/addons/gorillamap.pbo --server-pbo dist/@GorillaMapServer/addons/gorillamap_server.pbo
```

Сборщик создаёт оба PBO и `dist/GORILLA_MAP.zip`. Изменение общего PBO требует обновления у сервера и игроков и новой подписи. Изменение только серверного PBO требует обновления только серверного пакета.

Архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Сборка: [docs/BUILD.md](docs/BUILD.md). Игровые проверки: [docs/TESTING.md](docs/TESTING.md). Результаты облачных проверок: [docs/VALIDATION.md](docs/VALIDATION.md).

Сигнатуры API сверялись с официальным DayZ-Script-Diff, commit `e8204c69fcfd056ea29a9728990fd9f7941ce8a6`. Это не подтверждает компиляцию в конкретной версии игры. Карта и шрифты — ресурсы DayZ; панели и значки созданы для этого проекта. Сторонние моды и изображение референса в поставку не включены.
